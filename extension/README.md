# Code Lesson Checkpoints for VS Code

This companion keeps command execution on the learner’s machine.

1. Run **Code Lesson: Connect to Lesson** and enter the six-character code.
2. Run **Code Lesson: Open Checkpoints**.
3. Select a checkpoint, review its exact command, and choose **Run locally**.
4. Review the capped, locally redacted output before explicitly sharing it.

The extension never uploads source files and never runs a command without showing it in a confirmation dialog.
